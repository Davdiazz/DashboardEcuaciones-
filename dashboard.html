Método de la Ecuación Auxiliar

Para resolver la parte homogénea: a·y'' + b·y' + c·y = 0

Idea central
Se propone una solución de la forma y = e^(mx). Al sustituir en la EDO, los factores e^(mx) se cancelan y obtenemos un polinomio algebraico en m — la ecuación auxiliar (o característica). Sus raíces determinan completamente la forma de yh.
Propuesta: y = e^(mx) → y' = me^(mx) → y'' = m²e^(mx) Sustituir en a·y'' + b·y' + c·y = 0: a·m²e^(mx) + b·m·e^(mx) + c·e^(mx) = 0 e^(mx)(am² + bm + c) = 0 // e^(mx) ≠ 0 ∴ Ecuación Auxiliar: am² + bm + c = 0
Caso 1 — Raíces Reales Distintas
Δ = b²−4ac > 0
m₁ ≠ m₂ ∈ ℝ
y_h = C₁e^(m₁x) + C₂e^(m₂x)
Caso 2 — Raíces Reales Iguales
Δ = b²−4ac = 0
m₁ = m₂ = m
y_h = (C₁ + C₂x)e^(mx)
Caso 3 — Raíces Complejas
Δ = b²−4ac < 0
m = α ± βi
y_h = e^(αx)[C₁cos(βx)
+ C₂sin(βx)]
Ejemplos rápidos
Caso 1 — Reales distintas
y'' − 5y' + 6y = 0 Ec. aux: m² − 5m + 6 = 0 m₁=2, m₂=3 y_h = C₁e^(2x) + C₂e^(3x)
Caso 2 — Raíces iguales
y'' − 4y' + 4y = 0 Ec. aux: m² − 4m + 4 = 0 m = 2 (doble) y_h = (C₁+C₂x)e^(2x)
Caso 3 — Complejas
y'' + 2y' + 5y = 0 Ec. aux: m²+2m+5 = 0 m = −1 ± 2i y_h = e^(−x)[C₁cos2x+C₂sin2x]
Extensión a orden superior
Para EDO de orden n: aₙmⁿ + aₙ₋₁mⁿ⁻¹ + ... + a₁m + a₀ = 0 // Cada raíz real simple m → contribuye C·e^(mx) // Raíz real repetida k veces → (C₁+C₂x+...+Cₖxᵏ⁻¹)e^(mx) // Par complejo α±βi repetido k veces → e^(αx)[polinomio en cos/sin]

Método de Coeficientes Indeterminados

Para encontrar la solución particular yp cuando g(x) ≠ 0

Principio del método
Se propone una forma funcional para yp que "imita" a g(x), con coeficientes desconocidos (A, B, C…). Luego se sustituye en la EDO y se igualan coeficientes para determinar esos valores. Solo funciona cuando g(x) es de tipo exponencial, polinomial, seno/coseno o combinaciones de estos.
g(x) — Forzamiento Forma propuesta yp Observación
k (constante) A Si 0 no es raíz de la ec. aux.
kxⁿ (polinomio grado n) Aₙxⁿ + ... + A₁x + A₀ Polinomio completo de grado n
ke^(αx) Ae^(αx) Si α no es raíz de ec. aux.
ke^(αx) (α = raíz simple) Axe^(αx) Multiplicar por x (regla de modificación)
ke^(αx) (α = raíz doble) Ax²e^(αx) Multiplicar por x²
k·cos(βx) o k·sin(βx) A·cos(βx) + B·sin(βx) Siempre incluir ambos términos
e^(αx)·cos(βx) o sin(βx) e^(αx)[A·cos(βx)+B·sin(βx)] 1ª traslación
xⁿ·e^(αx) (Aₙxⁿ+...+A₀)e^(αx) Producto: polinomio × exponencial
Procedimiento paso a paso
① Resolver primero la ec. auxiliar
Hallar las raíces m₁, m₂, … para detectar posibles conflictos con yp.
② Proponer yp según la tabla
Identificar el tipo de g(x) y copiar la forma propuesta correspondiente.
③ Verificar regla de modificación
Si la forma propuesta duplica un término de yh, multiplicar por x (o x²).
④ Calcular yp', yp'' y sustituir
Reemplazar en la EDO original e igualar coeficientes a ambos lados.
⑤ Resolver el sistema y obtener yp
Con los valores de A, B, … reemplazar en la forma propuesta.
Ejemplo resuelto
EDO: y'' + 4y = 3x² // g(x) = 3x² → proponer y_p = Ax² + Bx + C y_p' = 2Ax + B y_p'' = 2A Sustituir: 2A + 4(Ax² + Bx + C) = 3x² 4A·x² + 4B·x + (2A+4C) = 3x² Igualar coeficientes: x²: 4A = 3 → A = 3/4 x: 4B = 0 → B = 0 1: 2A+4C = 0 → C = −3/8 y_p = (3/4)x² − 3/8

Solución Total — Principio de Superposición

La solución general es la suma de la solución homogénea y la particular

El Principio
Para una EDO lineal no homogénea, la solución general se construye sumando las dos componentes. Esto funciona gracias a la linealidad del operador diferencial: si yh anula el lado izquierdo y yp produce g(x), su suma cumple la ecuación completa.
y(x) = yh(x)
Solución homogénea
(constantes libres C₁, C₂…)
+
yp(x)
Solución particular
(coeficientes determinados)
=
ygeneral(x)
Solución general
(n constantes arbitrarias)
y(x) = C₁e^(m₁x) + C₂e^(m₂x) + y_p(x) // Las constantes C₁, C₂ se determinan con las condiciones iniciales // y(x₀) = y₀, y'(x₀) = y₁, ... (problema de valor inicial)
¿Por qué funciona la superposición?
Linealidad del operador L
L[y] = aₙy⁽ⁿ⁾ + … + a₀y es un operador lineal: L[u+v] = L[u] + L[v].
yh anula la ecuación
Por definición: L[yh] = 0.
yp produce g(x)
Por construcción: L[yp] = g(x).
∴ L[yh + yp] = 0 + g(x) = g(x) ✓
La suma satisface la EDO completa.
Aplicación de condiciones iniciales
Ejemplo — aplicar C.I. a la solución general: y(x) = C₁e^(2x) + C₂e^(3x) + (3/4)x² − 3/8 Condiciones: y(0) = 1, y'(0) = 0 y(0) = C₁ + C₂ − 3/8 = 1 → C₁ + C₂ = 11/8 y'(x) = 2C₁e^(2x) + 3C₂e^(3x) + (3/2)x y'(0) = 2C₁ + 3C₂ = 0 → C₂ = −2C₁ Sistema → C₁ = 33/8, C₂ = −11/4 y(x) = (33/8)e^(2x) − (11/4)e^(3x) + (3/4)x² − 3/8

Solución al problema planteado

Aplicación completa de los tres métodos a una EDO concreta

EDO del problema
y'' − 3y' − 4y = 3e^(2x), y(0) = 1, y'(0) = 0 // EDO de 2° orden, no homogénea, coeficientes constantes
❶ Ecuación Auxiliar → yh
Ec. homogénea: y'' − 3y' − 4y = 0 Ec. auxiliar: m² − 3m − 4 = 0 Factorizar: (m−4)(m+1) = 0 m₁ = 4, m₂ = −1 (reales distintas) y_h = C₁e^(4x) + C₂e^(−x)
❷ Coef. Indeterminados → yp
g(x) = 3e^(2x) → proponer y_p = Ae^(2x) // α=2 no es raíz → no hay modificación y_p' = 2Ae^(2x) y_p'' = 4Ae^(2x) Sustituir: 4Ae^(2x) − 3(2A)e^(2x) − 4Ae^(2x) = 3e^(2x) (4A − 6A − 4A)e^(2x) = 3e^(2x) −6A = 3 → A = −1/2 y_p = −(1/2)e^(2x)
❸ Superposición → Solución total + Condiciones iniciales
y(x) = y_h + y_p = C₁e^(4x) + C₂e^(−x) − (1/2)e^(2x) Aplicar condiciones iniciales: y(0) = 1: C₁ + C₂ − 1/2 = 1 → C₁ + C₂ = 3/2 y'(x) = 4C₁e^(4x) − C₂e^(−x) − e^(2x) y'(0) = 0: 4C₁ − C₂ − 1 = 0 → 4C₁ − C₂ = 1 Sistema: C₁ + C₂ = 3/2 ──┐ 4C₁ − C₂ = 1 ──┘ → sumar: 5C₁ = 5/2 → C₁ = 1/2 C₂ = 3/2 − 1/2 = 1 ✅ Solución final: y(x) = (1/2)e^(4x) + e^(−x) − (1/2)e^(2x)
Satisface la EDO original (verificable por sustitución)
Cumple y(0) = 1 y y'(0) = 0
Método sistemático y reproducible en cualquier EDO similar
Los tres métodos se aplican en secuencia sin ambigüedad

5 Ideas relevantes del aprendizaje

Conclusiones e insights fundamentales del proceso de aprendizaje

1

La ecuación auxiliar transforma una EDO en un problema algebraico

Proponer y = e^(mx) y sustituir en la EDO homogénea convierte un problema de cálculo diferencial en encontrar raíces de un polinomio. Esta idea de "cambio de representación" es profunda: resolver el polinomio es suficiente para conocer todas las formas posibles de la solución homogénea.

2

Los tres tipos de raíces generan tres comportamientos físicamente distintos

Raíces reales distintas → crecimiento/decaimiento puro. Raíces iguales → crecimiento polinomial modulado. Raíces complejas → oscilación amortiguada o sostenida. Esta clasificación no es solo matemática: refleja directamente si un sistema físico (circuito, resorte, fluido) diverge, converge o oscila.

3

La regla de modificación revela la "resonancia" del sistema

Cuando g(x) tiene la misma forma que un término de yh, la propuesta normal falla (el sistema ya absorbe ese tipo de función). Multiplicar por x o x² es la solución matemática, pero físicamente corresponde al fenómeno de resonancia: la entrada "sintoniza" con la frecuencia natural del sistema y la respuesta crece.

4

La superposición es una consecuencia directa de la linealidad

El principio y = yh + yp no es una fórmula arbitraria: emerge de que el operador diferencial L es lineal. Cualquier combinación lineal de soluciones homogéneas es también homogénea, y al sumar yp "corregimos" la ecuación para que cumpla el forzamiento. La linealidad es lo que hace manejable el problema.

5

Las condiciones iniciales determinan la solución única, no el método

Los tres métodos juntos producen la solución general, que tiene constantes arbitrarias. Las condiciones iniciales (o de frontera) son las que seleccionan la única solución del problema físico concreto. Esto enseña que hay infinitas soluciones posibles y que el contexto del problema es el que las restringe a una sola.
